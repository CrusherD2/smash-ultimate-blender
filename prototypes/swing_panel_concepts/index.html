Ultimate Swing Data: three layout concepts

Every element here exists in Blender's UI toolkit (lists, sub-panels, property split, joined buttons, collapsible sections), so each concept can be built without custom drawing. Sample data: a hair chain with five bones.

Full-width lists stacked top to bottom: chain, then bone, then that bone's settings in labelled groups. Nothing is squeezed into thirds.
