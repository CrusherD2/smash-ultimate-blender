Collision shapes: two directions and a new Add dialog

Today there are six sub-panels, and each shows an empty list and an empty dropdown menu even when it has no shapes. The Add dialog asks for a name, a bone and numbers before the shape exists, so you're placing it blind. Sample data: a rig with 7 shapes.

A. One "Collision Shapes" panel

All six types share one list. Type buttons filter it and show counts. Each row shows the bone the shape is attached to. Add picks a type and creates the shape right away on the selected bone.
