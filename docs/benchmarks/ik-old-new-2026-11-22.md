# IK benchmark: old versus installed version

Old: `028e0a43afad2e88dd7aecc3b3cda5fa42ac94ff`, complete source from the publishing repository. New: installed IK implementation, included in release 5.1.0.

Blender 5.2.0 LTS background CPU timings. Same deterministic synthetic 15-bone rig, both arms and legs, rotation keys every frame. Three fresh-rig runs per clip length/version; medians below. Startup, registration, animation generation and accuracy checks excluded. Old runs preceded new runs; small timing differences should be treated cautiously. No meshes or viewport drawing. Creation means IK controls only, not full Animation Rig creation with fingers/custom components.

| Frames | Operation | Old seconds | New seconds | Speedup |
| --- | --- | ---: | ---: | ---: |
| 24 | Create IK controls | 0.0902 | 0.0661 | 1.37x |
| 24 | Match IK to FK | 0.5729 | 0.1263 | 4.54x |
| 24 | Bake IK to FK and remove IK | 0.1121 | 0.0971 | 1.15x |
| 120 | Create IK controls | 0.0867 | 0.0674 | 1.29x |
| 120 | Match IK to FK | 2.3262 | 0.6754 | 3.44x |
| 120 | Bake IK to FK and remove IK | 0.2768 | 0.2089 | 1.33x |

## Accuracy

- Old: worst matching matrix error 4.1872263e-06; worst bake matrix error 1.0102987e-05.
- New: worst matching matrix error 5.1856041e-06; worst bake matrix error 2.5033951e-06.

All frames and all 14 non-root original bones checked, including toes. All 12 scenarios completed; both versions stayed below 0.0001 absolute matrix-element error. Bake excludes matching; control creation excludes matching. No user blend files opened or saved.

Run `tests/benchmark_ik_old_new_blender.py` in factory background Blender with `--python-exit-code 1`. Set `SUB_BENCH_ROOT` to a complete source tree and `SUB_BENCH_OUTPUT` to a new JSON output path; `SUB_BENCH_RUNS` defaults to 3. The registration fixture isolates configuration and disables unrelated network/user-library operations. Raw results/logs: `.tests/ik-old-new/`.
